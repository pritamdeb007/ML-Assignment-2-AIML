# Machine Learning Assignment 2





### Phishing Website Classification Using Machine Learning



#### 1\. Problem Statement



The objective of this project is to develop machine learning classification models to identify whether a website is legitimate or phishing based on its website-related characteristics.



Five supervised machine learning classification algorithms will be implemented and evaluated using the same dataset.



#### 2\. Dataset Description



\*\*Dataset Name:\*\* Phishing Websites



\*\*Source:\*\* UCI Machine Learning Repository



\*\*Dataset ID:\*\* 327



\*\*Dataset Link:\*\* https://archive.ics.uci.edu/dataset/327/phishing



\*\*Problem Type:\*\* Binary Classification



\*\*Number of Instances:\*\* 11,055 (as reported in UCI metadata)



\*\*Number of Input Features:\*\* 30



\*\*Target Variable:\*\* Result



\*\*Missing Values and Duplicates:\*\* To be inspected and documented during data preparation.



\*\*Preprocessing:\*\* To be documented after dataset inspection and implementation.



\*\*Train-Test Split:\*\* To be documented after model training.



\*\*Class Distribution:\*\* To be calculated from the actual dataset.



#### 3\. GitHub Repository Link



Repository: https://github.com/pritamdeb007/ML-Assignment-2-AIML



#### 4\. Machine Learning Models



The following five classification algorithms will be implemented using Scikit-learn:



1\. Logistic Regression

2\. Decision Tree Classifier

3\. K-Nearest Neighbor Classifier

4\. Gaussian Naive Bayes

5\. Support Vector Machine



#### 5\. Model Evaluation Metrics



All five models will be evaluated using:



\- Accuracy

\- AUC Score

\- Precision

\- Recall

\- F1 Score

\- Matthews Correlation Coefficient (MCC)



#### 6\. Model Comparison



The comparison table and performance observations will be updated after training and evaluation.



#### 7\. Streamlit Application



The application will provide:



1\. CSV test dataset upload.

2\. Classification model selection.

3\. Evaluation metrics display.

4\. Confusion matrix or classification report.



The application will load previously trained models without retraining on the uploaded test dataset.
